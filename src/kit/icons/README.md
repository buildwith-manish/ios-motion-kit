# kit/icons

Typed inline SVG icons from Lucide, colored by the active kit theme. The source subset is pinned in `NOTICE` and
licensed in `LICENSE`; run `node scripts/kit_build_icons.mjs` after adding or replacing a source SVG.

```tsx
import {Icon, IconTile, SPRING, iosSpring} from '../kit';

export const Scene: React.FC<{frame: number; fps: number}> = ({frame, fps}) => {
  const time = frame / fps;
  const drawOn = iosSpring(time - 0.4, SPRING.SNAPPY);
  return (
    <div style={{display: 'flex', alignItems: 'center', gap: 24}}>
      <Icon name="wallet" size={40} tone="accent" drawOn={drawOn} />
      <IconTile name="house" size={72} fill="glass" />
      <Icon name="circle-check" size={32} tone="positive" />
    </div>
  );
};
```

| Export | Purpose | Props |
| --- | --- | --- |
| `Icon` | Render one inline Lucide glyph. | `name`, `size` (24 logical px), `tone` (`primary`, `secondary`, `tertiary`, `accent`, `positive`, `warning`, `negative`, `onAccent`), `stroke` (auto optical width), `drawOn` (0..1), `theme`, `label` |
| `IconTile` | Generic rounded-square icon backing. | `name`, `size` (64), `iconSize`, `tone`, `fill` (`glass` or `tinted`), `frame`, `drawOn`, `theme` |
| `ICON_NAMES` / `IconName` | The supported name list and union type. | 80 names covering finance, housing, family, work, transport, health, maps, status, and arrows |
| `ICON_COMPONENTS` | Generated name-to-SVG component map. | Generated by `scripts/kit_build_icons.mjs` |

`Icon` and `IconTile` are pure render functions: pass the frame-derived progress to `drawOn`; no primitive reads the
Remotion clock. Values outside the supported ranges throw rather than silently produce invalid SVG styles.
