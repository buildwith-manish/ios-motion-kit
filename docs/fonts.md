The theme font stacks (`src/kit/tokens/themes.ts`) also name `-apple-system`, `SF Pro Display/Text`, `system-ui`, `Helvetica Neue`, `Arial`. These are fallbacks only: no file of them is in the repo, and a frame painted in one of them is a bug (see below).

## Rules

- Do not add system fonts you cannot redistribute (SF Pro, Helvetica Neue, Arial, Segoe UI, ...). Add only fonts whose license allows redistribution, put the license file next to them, and add a row above.
- Kit fonts load through `useKitFonts()` / `<KitFontGate>` / `withKitFonts(Root)` (src/kit/tokens/fonts.ts, FontGate.tsx): the render waits for every file; a failure or a 25 s timeout cancels the render with an error naming the font ("Inter 700 latin", file path).
- CI (`kit-main-ci`, `[qa]` push, job "Font check") runs `scripts/kit_font_still.mjs`: it fails if any `Inter` face is not `loaded` in `document.fonts` or on-screen text renders in another family. Report and stills: artifact `fonts`.
- Width tables for another font: `python3 scripts/kit-font-metrics.py` (see src/kit/text/README.md).

## Type scale (Theme.typeScale, design px at 1080 short side)

hero 160 (120..200), number 96, figure 72, title 56, stat 48, label 36, caption 30, footnote 28. Floors match `scripts/kit_layout_lint.config.json`: text >= 28, label >= 36, hero 120..200. `typeScaleOf(theme)`, `scaleStyle(theme, role)`, and `numberSize(text, maxWidth, {min, max})` to fit hero numbers. The older `Theme.type` roles are unchanged.
